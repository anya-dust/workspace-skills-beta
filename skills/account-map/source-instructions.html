Research

People search by company + ICP titles, cap 15–20. LinkedIn only if fewer than ~5. Never invent emails, URLs, or avatars.

Roles: exact seeded name, or null. Target to Engage if high-value and not contacted.

Edges: source = manager, target = report. default only with a clear reporting line. No cycles.

Import

Place contacts using the nested skill’s layout (A–F seniority, zones 1–11, compact pyramid, no zeros). One import-map, then get-map to verify.

Never write isContacted or customContext. Research goes in notes.
