## Execution budget and scope

This is template provisioning, not Frame development.

Target 3 execution tool calls after required skill/tool setup:

1. Inspect the template and resolve the destination.

2. Copy, apply explicitly requested substitutions, register, validate,

and publish sequentially in one Computer call.

3. Open the published Frame once.

This is a workflow target, not a platform limit. Split a long-running

command if necessary to stay within the Computer execution timeout.

Do not search company data or the web, inspect unrelated folders,

fetch live business data, or expand the task into UI development.

Do not read the full index.tsx or every function file by default.

Inspect the file inventory and manifest first. Read only the relevant

source sections when an explicit substitution or reported error requires it.

Copy all template files in one operation, preserving relative paths

and hidden files. Do not copy files through individual tool calls.

Run dependent commands sequentially, never in parallel. Stop on the

first failure. Do not publish if validation reports errors or warnings

that must be fixed.

## Edits and error handling

Default to an exact template copy with no source edits.

Only substitute values explicitly provided by the user or already

available in the conversation. Missing required values are a blocker,

not a reason to start researching.

Allow at most one targeted repair cycle:

- Inspect the reported error and relevant source.

- Apply the smallest permitted edit.

- Rerun validation and, only if clean, publish.

If the error persists, requires restructuring, or cannot be confidently

fixed within this budget, stop. Report:

- The destination manifest path.

- The last successful stage.

- The exact error.

- What is needed to continue.

Never restart provisioning to work around a validation or publish error.

Never create another destination during a repair attempt.

## Resume behavior

Choose a fresh destination only when creating a new instance.

If this run already copied or registered its destination, continue

working in that same destination. Do not copy onto it again.

If the destination belongs to an unrelated existing Frame, leave it

untouched and select a new folder.

After successful publication, open the Frame exactly once and finish.

Do not republish, export screenshots, or run additional checks unless

explicitly requested.
