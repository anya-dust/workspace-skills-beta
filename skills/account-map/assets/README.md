# Account Map Kit (flat)

Skill **Files** is a flat picker. This folder is already flat so you can select-all.

## Upload

1. Paste `SKILL.md` into the skill instructions (name: `Account Map`).
2. In this folder, select **every file except `SKILL.md`** and drop them on
   **Upload files**.
3. `__` in a filename is a directory. `LAYOUT.txt` is the map the agent uses to
   rebuild `AccountMap/` on the Pod.

Do not zip. Do not pick files from nested folders — there are none.

## Names

`functions__lib__store.ts` → `functions/lib/store.ts`  
`ui__ContactCard.tsx` → `ui/ContactCard.tsx`  
`frame_manifest.json` → `manifest.json` (the Frames v2 manifest)
